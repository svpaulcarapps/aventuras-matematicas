# Aventuras matemáticas en San Vicente de Paúl

Juego OAOA para el alumnado del Colegio San Vicente de Paúl (Cartagena).

- Juego: https://svpaulcarapps.github.io/aventuras-matematicas/
- La interfaz se sirve desde este repositorio (GitHub Pages).
- Las partidas, cuentas y ranking se guardan en el proyecto de Apps Script **JUEGOS OAOA** (cuenta del colegio), al que el juego llama sin cuenta de Google (doPost).
- Código fuente editable: `juegos/aventuras-matematicas` en el repositorio oaoa-biblioteca; la versión publicada se genera con `github/build-pages.mjs`.

No subir datos de alumnos, contraseñas ni claves a este repositorio.
